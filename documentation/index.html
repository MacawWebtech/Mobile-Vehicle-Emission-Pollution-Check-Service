Clearway documentation

A premium, multi-page Bootstrap 5 template for doorstep vehicle emission testing. No build tools required.

1. Install

  1. Unzip the package and open pages/index.html in a browser.
  2. For a local server: npx serve . or python3 -m http.server 8080.
  3. Upload the whole folder to your host. The root index.html forwards to pages/index.html.

Bootstrap, Bootstrap Icons and fonts load from CDNs. To self-host, see assets/fonts/README.md and point the <link> tags at local copies. Keep the id="bootstrap-css" on the Bootstrap link: the RTL toggle swaps its href.

Photos & maps

All imagery is real photography (Unsplash License). Pages load WebP versions from Unsplash's CDN with a responsive srcset. Run bash download-images.sh https://www.your-domain.com to save them into assets/images/photos/ and relink every page to the local files. Replace any photo by dropping a file with the same name into that folder.

Every <img> carries data-photo="key" so you can find it quickly. Coverage and Contact use live Google Maps embeds — edit the q= parameter.

3. Page structure

Two home pages are included — pick one and point the logo/Home link at it, or keep both under the Home dropdown. Every public page shares the same header (top promo bar, logo, nav, theme + RTL toggles, Book Test button, hamburger below 1024px) and footer (road band, newsletter, links, helpline, WhatsApp, service hours, socials).

Edit them in :root at the top of style.css; dark equivalents live in dark-mode.css under [data-bs-theme="dark"].

Typography & spacing

Two fonts via --cw-font-display and --cw-font-body. Spacing follows an 8px scale: --s1 (8px) to --s12 (96px).

Dark mode

The inline script in each <head> applies the saved theme (or OS preference) before first paint. Any button with class theme-toggle switches it; window.cwSetTheme("light" | "dark" | "system") is available for custom controls.

RTL

Any .dir-toggle button sets <html dir="rtl"> and loads bootstrap.rtl.min.css. Template CSS uses logical properties (inset-inline-start, margin-inline-end); exceptions are in rtl.css. To ship an RTL-only site, set dir="rtl" in the HTML and link the RTL Bootstrap build directly.

5. Components

  • Buttons: .btn-cw, .btn-cw-accent, .btn-outline-cw, .btn-ghost, .btn-icon, .btn-link-cw — all ≥ 44px tall.
  • Status badges: .cw-badge + badge-scheduled · badge-ontheway · badge-completed · badge-due · badge-expired.
  • Route divider: .route-divider with .route-node / .route-path.
  • Gauge: .cw-gauge SVG — the .needle rotation sets the reading (−90° low … +90° high).
  • Certificate: .cw-cert, .cw-stamp (.is-sm, .is-expired), .cw-valid-ribbon.
  • Skeletons: wrap content in [data-skeleton] with a .skel-view and a .real-view; add .is-loaded when your data arrives (done automatically by dashboard.js in demo mode).
  • Validation: add class="cw-validate" to a form. Override messages per field with data-msg-required, data-msg-pattern, data-msg-type, data-msg-short, data-msg-min, data-msg-max; confirm fields use data-match="otherId". Success text: data-success; optional data-redirect.
  • Countdowns: [data-due-days] cards (negative = expired) compute days left, progress bar and badge.
  • Toasts: any element with data-demo-toast="Message" on dashboard pages.

6. Integrations

  • Formspree: set the form action to your endpoint. Netlify: remove action, add data-netlify="true".
  • Mailchimp: footer form — paste your list action URL and the hidden bot field name.
  • Google Maps: replace each .cw-map-placeholder img with the iframe in the adjacent HTML comment.
  • Booking calendar / API: dashboard.js §06 — the submit handler is marked API:.
  • Stripe / PayPal: mount points #stripe-card-element, #stripe-card-modal, #paypal-button-container.
  • Pincode coverage: SERVICEABLE map in main.js §06.

7. Accessibility & SEO

Colour pairs are checked to WCAG 2.1 AA (4.5:1 for text). All interactive elements have visible focus rings, labels or aria-labels, and work with the keyboard; a skip link starts every page. Motion is reduced for prefers-reduced-motion and on phones.

SEO: unique titles (≤ 60 chars), 150–160 character descriptions, one <h1> per page, JSON-LD, descriptive alt text, WebP photos, sitemap.xml and robots.txt. Replace https://www.example.com everywhere with your domain.
